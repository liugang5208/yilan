优化说明
1. 标题栏独立：将"当前商品"标签和操作按钮提升到独立的 header 行，视觉层次更清晰，按钮更易点击。
2. 字段 label 统一：采用"输入组"风格（label 作为前缀块），与 Bootstrap input-group 视觉一致，对齐整齐。
3. 两列网格布局：文字字段和图片上传均采用 2 列 grid，间距统一，不再依赖 flex 嵌套。
4. 图片预览区优化：预览图与上传框分离，增加尺寸提示文字，有图时显示缩略图，无图时显示占位框。
5. 按钮位置调整：操作按钮移至顶部 header 右侧，符合"先看内容再操作"的交互习惯，同时避免右侧竖排按钮占用空间。
6. 整体风格统一：边框色、背景色、字号与页面其他 section 保持一致（#dce3ea / #f5f7fa / 12px）。
